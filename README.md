## スマホアプリ版（app/） — 価値観マッチングアプリ

恋愛タイプ診断（16タイプ）と価値観の回答から「相性％」を出して、相性のいい人を紹介する iOS / Android 向けの恋活アプリです。

- 登録：**18〜100歳・全国どこからでも可**（高校生は不可）
- 狙い：関東の 20〜50歳（検索の初期値は 20〜50歳、同じ都道府県の人を少し優先表示）
- 集客：Instagram 広告 → **Web の診断ページ**（登録不要）→ アプリ。診断結果はストーリーズ用画像でシェア

| | |
|---|---|
| アプリ | Expo (React Native) + TypeScript + Expo Router — `app/` |
| バックエンド | Supabase（認証・PostgreSQL・リアルタイム・画像保存） — `supabase/` |
| 課金 | RevenueCat（App Store / Google Play のサブスクリプション） |
| 診断LP | 静的サイト（esbuild）。診断ロジックはアプリと共通 — `web/` |

## できること

- メール登録 → プロフィール作成（写真・生年月日・居住地・自己紹介）
- **年齢確認**：本人確認書類をアップロード → 運営が目視で承認
- **恋愛タイプ診断**：20問 → 4軸（情熱/穏やか・リード/寄り添い・いつも一緒/自分時間・直感/計画）で16タイプに分類。結果はシェア可能
- **価値観の質問**：結婚・子ども・休日・連絡頻度・お金・お酒・タバコ
- **相性％**：診断60%＋価値観40%で計算（リード/寄り添いだけは「逆」の方が相性◎）。おすすめは相性順、共通の価値観も表示
- **さがす**：異性・年齢確認済み・希望年齢の範囲内を相性順に表示。いいね / スキップ
- **マッチング**：お互いにいいねで成立 → リアルタイムチャット
- **通報・ブロック・マッチ解除**、退会（アカウント削除）
- **禁止ワード検知**：LINE ID・電話番号・メールアドレス・援助・パパ活・未成年を示す語などを含むメッセージ/プロフィールをサーバー側で拒否
- **収益化**（男性有料モデル）

| | 無料 | プレミアム |
|---|---|---|
| いいね | 1日10回 | 1日100回 |
| メッセージ送信 | 女性のみ | ○ |
| いいねしてくれた人を見る | 人数のみ | ○ |

課金や年齢確認の判定はすべてデータベース側（RLS とトリガー）で行っているため、アプリを改造されても回避できません。
