# 事業として始めるために

> ⚠️ ここに書いた法律・料金の情報は 2026年11月時点の一般的な内容です。必ず最新の公式情報を確認し、可能なら行政書士・弁護士に相談してください。

## 1. 公開前に必ず必要な手続き（やらないと違法）

### ① インターネット異性紹介事業の届出（出会い系サイト規制法）
- 恋愛目的で異性を紹介し、ユーザー同士がメッセージできるサービスは該当します
- **事業を始める前に**、事務所の所在地を管轄する警察署経由で都道府県の公安委員会に届出
- 無届での運営は刑事罰の対象。個人でも届出できます（手数料は不要）
- 届出後の義務（このアプリに実装済みのもの ✅）
  - ✅ 利用者が18歳以上であることの確認（公的書類で生年月日を確認）
  - ✅ 18歳未満の利用禁止の明示
  - ✅ 禁止誘引行為（未成年の誘引・対償を伴う交際の誘引）の書き込みを見つけて削除する仕組み
  - ⬜ 運営側の日々の監視・通報対応（**これは人手で毎日やる必要あり**）

### ② 電気通信事業の届出（総務省）
- ユーザー同士のメッセージを仲介するため、電気通信事業の届出が必要になる場合が大半です。総合通信局に届出（無料）
- 通信の秘密の保護義務あり：**運営者がメッセージを理由なく閲覧してはいけません**（通報があった場合の調査など、正当な理由と規約上の同意が必要）

### ③ その他
- 特定商取引法に基づく表記（`app/src/lib/legal.ts` にひな形あり）
- 利用規約・プライバシーポリシーの完成（同上）
- 個人情報保護法への対応（本人確認書類は特に厳重に。保存期間を決める）

## 2. 稼ぐ仕組み

日本のマッチングアプリの定番「**男性有料・女性無料**」モデルを実装済みです。

- 女性を無料にする → 女性が集まる → 男性が「メッセージしたい」ので課金する
- 男性はマッチングまで無料。**マッチして「メッセージを送りたい」瞬間が最も課金されやすい**

### 価格の目安（大手の相場に合わせた例）
| プラン | 価格 | 月あたり |
|---|---|---|
| 1か月 | 3,980円 | 3,980円 |
| 3か月 | 9,800円 | 約3,270円 |
| 6か月 | 16,800円 | 2,800円 |

### 収支の試算（あくまで仮定の計算例）
- 有料会員 300人 × 平均 3,300円/月 = 約99万円/月の売上
  - ストア手数料 15%（Small Business Program 適用時）→ 約84万円
  - 固定費：Supabase Pro 約25ドル/月、Apple Developer 年99ドル、Google Play 初回25ドル、RevenueCat は一定の売上までは無料
- **最大の支出は集客（広告費）です**。マッチングアプリの広告単価は高く、ここで赤字になるのが典型的な失敗パターン

## 3. Instagram 広告での集客（関東・20〜50歳を狙う）

### 基本の配信設定（Meta 広告マネージャ）
- 目的：まずは **Web の診断ページへの誘導**（`web/`。登録不要なのでタップ後の離脱が少ない）。アプリ公開後はアプリインストール広告も併用
- 最適化：診断ページの `CompleteDiagnosis`（診断完了）や `Lead`（ストアへタップ）をコンバージョンに設定
- 地域：東京都・神奈川県・埼玉県・千葉県（反応を見て茨城・栃木・群馬を追加）。登録自体は全国どこからでも可能
- 年齢：20〜50歳（登録は18〜100歳まで可能。広告のターゲットだけ絞る）。**20代 / 30代 / 40代で広告セットを分ける**（年代ごとに刺さる訴求が違う）
- 性別：まずは**女性向けに予算を厚く**（女性が集まらないと男性の課金が発生しない）
- 配置：Instagram のリール・ストーリーズ・フィード

### 刺さりやすい広告のつくり方
- **診断を主役にする**：「あなたの恋愛タイプは16タイプのどれ？」「3分でわかる恋愛タイプ診断」→ 恋活アプリっぽさを抑えて、まず診断をやってもらう
- タイプ名とイラストを並べたリール（例：「🔥全力ヒーロー型 × 💐一途な献身型 は相性98%」）
- 年代別の訴求
  - 20代：診断の楽しさ・相性％・友達とシェア
  - 30代：「価値観（結婚・子ども）が合う人だけ」「年齢確認済みで安心」
  - 40代：「落ち着いた大人の恋」「同じペースで歩める人」
- 素材は最低 5〜10 本を用意して少額でテストし、反応の良いもの（インストール単価が安いもの）に予算を寄せる

### 計測（次にやること）
- Meta SDK / App Events を入れて「インストール → 登録 → 年齢確認 → 課金」まで計測すると、どの広告が**課金につながっているか**がわかる（今は未実装）
- iOS は ATT（トラッキング許可）の影響で計測が粗くなる点に注意

### シェアで広告費を下げる
- アプリ・Web 両方に**ストーリーズ用の結果画像（1080×1920）**を実装済み。画像の下部に「こいまち で恋愛タイプ診断」を入れているので、見た人が検索して診断ページに来る流れを作れる
- Web の結果ページはURLに結果が入るので、リンクをシェアされても同じ結果が表示され「あなたも診断する」に誘導される

## 4. 大手（Pairs・タップル・with など）に勝つための戦略

マッチングアプリは「人がいないアプリには誰も来ない」ビジネスです。大手と同じ土俵で戦うと勝てません。

1. **「価値観・相性」で差別化**（実装済み）：顔写真だけで選ぶ大手との違いを打ち出す。診断はそれ自体が広告・話題になる
2. **関東から始める**：広告を関東に集中して密度を作る（全国に薄く広げると「近くに誰もいない」状態になる）。登録は全国から受け付け、同じ都道府県の人を少し優先して表示
3. **女性を先に集める**：安全性（年齢確認・通報対応の速さ）を前面に出す。女性が集まれば男性は自然に来る
4. **お金をかけない集客**：SNS（X・TikTok・Instagram）でのニッチなコミュニティへの発信、趣味のイベント・オフ会との連携、App Store の検索対策（ASO）
5. **審査・通報対応の速さを売りにする**：年齢確認を数時間以内に承認できると離脱が大きく減る
